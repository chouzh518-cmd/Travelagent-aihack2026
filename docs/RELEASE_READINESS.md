# リリース準備状況

更新日：2026-09-22

## 現在の提供範囲

ローカルで実行できる出張計画デモです。社員は登録済みプロジェクトの選択、資料のアップロード、条件の補足、ローカル模擬行程の確認、規程根拠の閲覧、計画書の生成、メール下書きの編集を行えます。システムは予約、メール送信、規程適合の判定を自動で行いません。

## ローカル起動

```powershell
.\.venv\Scripts\python.exe app.py
```

ブラウザーで `http://127.0.0.1:8765/` を開きます。インターネット公開時には `APP_ACCESS_PASSWORD` と、正確な `APP_TRUSTED_HOSTS` または `RENDER_EXTERNAL_HOSTNAME` を設定してください。

## 検証済みの項目

- `node --check static/workspace.js` が成功。
- `python -m py_compile` が成功。
- `.venv` の `unittest discover -s tests -q` が 56/56 件成功。
- ローカルの一連の処理：プロジェクト資料 → 模擬見積り → `/api/run` → `needs_rule_review`。規程検索は `needs_human_review` を返します。
- 関連性のない検索語は距離しきい値を超えると `not_found` を返し、根拠を捏造しません。
- 同一 API への 31 回目のリクエストは、再試行までの待機案内を含む `429` を返します。
- モデルの実使用ルートは既定で `orcarouter/free` です。有料ルートには `ORCAROUTER_ALLOW_PAID=true` の明示設定が必要です。

## 外部依存が利用できない場合

| 依存関係 | 通常の動作 | 縮退時の動作 |
| --- | --- | --- |
| FastEmbed/Chroma | ローカル資料検索と規程根拠の取得 | プロジェクト画面は利用可能。社員は条件を手動入力し、検索・アップロードは後で再試行 |
| OrcaRouter | 資料に基づく質問応答とメール生成 | ローカルルールによる抽出、原文根拠の表示、編集可能なメールテンプレート |
| 鉄道・ホテル・在庫 API | 現在は未設定 | 模擬値であることを明記し、実際の購入可能性や有効な見積り順位は表示しない |
| 企業メールシステム | 現在は未設定 | 編集・コピー可能で未送信と明示された下書きのみを生成 |
| 企業 ID システム | 現在は未設定 | ローカルまたはアクセスを制限したデモ環境に限り、匿名化した資料を使用 |

## 公開前に人が確認する項目

1. Docker イメージのビルドと、対象デプロイ環境での実際のヘルスチェック。
2. 企業 ID、権限分離、資料の保管期間、バックアップの方針。
3. 実際の交通・宿泊サービスの利用規約、認証情報、料金、フィールド検証。
4. 有料モデルルートや実際のメール送信を有効にする場合の組織承認。
