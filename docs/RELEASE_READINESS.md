# 最终版本交付说明

更新日期：2026-09-22

## 当前交付范围

这是一个可本地运行的差旅计划演示版本。员工可以选择登记项目、上传资料、补充条件、查看本地模拟行程、查看规程证据、生成计划书和编辑邮件草稿。系统不会自动订票、发送邮件或判定规程合规。

## 本地启动

```powershell
.\.venv\Scripts\python.exe app.py
```

浏览器打开 `http://127.0.0.1:8765/`。公开监听必须同时设置 `APP_ACCESS_PASSWORD` 和精确的 `APP_TRUSTED_HOSTS` 或 `RENDER_EXTERNAL_HOSTNAME`。

## 已验证证据

- `node --check static/workspace.js` 通过。
- `python -m py_compile` 通过。
- `.venv` 中 `unittest discover -s tests -q`：55/55 通过。
- 本地端到端流程：项目资料 → 模拟报价 → `/api/run` → `needs_rule_review`；规程检索返回 `needs_human_review`。
- 无关检索词在距离阈值外返回 `not_found`，不会生成伪证据。
- 同一接口第 31 次请求返回 `429`，并带等待提示。
- 模型默认实际使用 `orcarouter/free`；付费路由必须显式设置 `ORCAROUTER_ALLOW_PAID=true`。

## 外部依赖不可用时的处理

| 依赖 | 正常路径 | 降级路径 |
| --- | --- | --- |
| FastEmbed/Chroma | 本地资料检索和规程证据 | 项目页仍可打开；员工手动输入条件，检索和上传提示稍后恢复 |
| OrcaRouter | 资料依据问答和邮件生成 | 本地规则抽取、原文证据和可编辑邮件模板 |
| 铁路、酒店、库存 API | 当前未配置 | 使用明确标记的本地模拟值；不显示真实可购买性或有效报价排名 |
| 企业邮件系统 | 当前未配置 | 只生成可编辑、可复制、明确未发送的邮件草稿 |
| 企业身份系统 | 当前未配置 | 仅限本地或受限演示环境，使用去敏资料 |

## 发布前仍需人工确认

1. Docker 镜像构建和目标部署平台的真实健康检查。
2. 企业身份、权限隔离、资料保留和备份策略。
3. 真实交通及住宿服务的条款、凭据、费用和字段验证。
4. 组织授权后再启用付费模型路由或真实邮件发送。

在上述事项完成前，版本应以本地演示或受限试用方式发布；不得把模拟行程、规程证据候选或邮件草稿描述为已预约、已合规或已发送。
