# BizTrip-Copilot（ビズトリップ・コパイロット）- 出張計画特化型AIエージェント

BizTrip-Copilotは、出張や学会参加に伴う「規程の確認」「最安値・経路の検索」「承認申請メールの作成」という不毛な事務作業を劇的に削減する、**出張計画特化型の自律型AIエージェント**です。

高価なエンタープライズ向けシステム（Concur等）が導入しづらい中小企業や大学研究室に向けた、軽量かつ実用的なソリューションとして開発されました。

## 💡 コンセプト：「自律性100%」ではなく「絶妙な距離感の相棒」

勝手に決済まで走ってしまう危険な「100%自動化」はあえて避け、規程違反を先回りして検知し、最後の送信ボタンだけは人間に委ねる「**Human-in-the-Loop（人間の介在）**」をガバナンスの基本としています。

「**曖昧なルールの読解はAI（RAG）、絶対にミスれない計算は堅牢なシステム（プログラム）**」と役割を徹底的に分離することで、ハルシネーション（架空の金額やホテルの提示）を防ぎ、実運用に耐えうるセキュリティと低コスト（1回数十円）を実現しました。

## ✨ 5つのコア機能

1. **必要なのは自然言語だけ（入力・解析フェーズ）**
   「来週の金曜から2泊3日で東京の学会へ」といったチャットから、システムが自動で「出張目的」「目的地」「行程日時」を抽出。不足情報があればAIが自律的に質問を返し、入力漏れを防ぎます。
2. **会社のルールを記憶する（RAGによる規程チェック）**
   利用者が追加した自社の「出張旅費規程（PDF/Markdown/画像等）」を読み解き、役職ごとの宿泊費上限などのルールをAIが正確に参照します。資料にない規程は勝手に補いません。
3. **費用と時間のタイパを測る（比較・最適化）**
   交通費・宿泊費の合算や移動時間の計算は、LLMではなくプログラム側の決定論的ロジックで行います。価格の安さと移動時間の短さ（タイムパフォーマンス）を評価し、最適にソートして提案します。
4. **ルール違反を未然に防ぐ（合規性自動判定）**
   社内規程と計算結果を照らし合わせ、宿泊費上限を超過するプランには「要承認」の警告ラベルを自律的に付与し、差し戻しの手間を削減します。
5. **最後の「めんどくさい」を消す（承認メール生成）**
   選択したプランと規程審査結果を元に、上司向けの承認申請メール（`.eml`形式）の下書きを生成。ローカルメーラー（Outlook等）で開いて最終確認・送信が可能です。

---

## 🔄 処理の流れ

```text
資料追加または日本語で相談
  → 条件を会話で整理（AIが不足条件をヒアリング）
  → 条件を確認し、規程データ（RAG）の該当箇所を検索
  → 交通・費用の模擬プランと規程根拠を比較・合規性判定
  → 利用者が最適なプランを選択
  → 承認メール下書き（.eml）を生成・人間が編集・送信

(※ 予約、承認、メールの自動送信、規程適合の最終判断はシステムで行わず、利用者の確認が必要です。)
```

## 📂 構成とアーキテクチャ

| パス | 用途 |
|---|---|
| `app.py` | HTTP サーバー、API、入力検証、アクセス制御 |
| `templates/`, `static/` | 日本語画面とブラウザー側のフロントエンド処理 |
| `agents/`, `rag/`, `llm/` | 資料に基づく質問応答とモデル制御（OrcaRouter経由） |
| `core/` | 条件抽出、決定論的な費用計算、合規性・行程検証 |
| `policy_import/` | PDF等の資料抽出、OCR、チャンク分割、ベクトル索引 |
| `tools/` | ローカル模擬データと外部連携の境界 |
| `data/offers/` | 安定動作用の模擬見積りサンプル |
| `config/`, `schemas/` | 設定、Pydantic等によるAPI・データ形式定義 |

## 🚀 動作環境とローカル起動

Python 3.12 が必要です。初回のセマンティック検索時に FastEmbed モデル（約 220 MB）をダウンロードします。依存関係は `requirements.txt` を参照してください。

**Windows PowerShell:**
```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

**macOS / Linux:**
```bash
python3.12 -m venv .venv
./.venv/bin/python -m pip install --upgrade pip
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python app.py
```

既定の URL は `http://127.0.0.1:8765` または `https://travelagent-6-igip.onrender.com/`、ヘルスチェックは `/healthz` です。ローカルではログインを要求しません。パスワードなしの状態でインターネットに公開しないでください。

## ⚙️ 環境変数

| 変数 | 用途 |
|---|---|
| `APP_BIND_HOST` | 待ち受け先。ローカル既定値は `127.0.0.1`、Render は `0.0.0.0`。 |
| `PORT` | HTTP ポート。ローカル既定値は `8765`、Render Blueprint は `10000`。 |
| `APP_DATA_DIR` | 実行時資料・索引・出力の保存先。Render 設定は `/var/data`。 |
| `APP_ACCESS_PASSWORD` | 公開環境で必須のチーム共有アクセスパスワード。 |
| `APP_TRUSTED_HOSTS` | 許可する正確なホスト名をカンマ区切りで指定。 |
| `ORCAROUTER_API_KEY` | 任意。設定しない場合、LLM機能はローカルルールとテンプレートへ縮退動作します。 |

*(※ 秘密情報は Render の Environment Variables 等に登録し、ソースコードや Git に保存しないでください。)*

## ☁️ Render へのデプロイ

リポジトリの `render.yaml` は Docker Web Service を設定します。無料 Web Service のファイルシステムは一時的で、アップロード資料や索引はスリープ後に失われる可能性があります。永続保存が必要な運用には無料プランを使用しないでください。詳細は `DEPLOY_RENDER.md` を参照してください。

## 🔒 セキュリティと制約

* AIが構造化条件や規程の根拠を推測ででっち上げる（ハルシネーション）ことはありません。未確認事項は利用者が目視で確認してください。
* 鉄道、航空、宿泊、在庫、天気などの本番 API や、経理システムへの自動決済・メール自動送信は接続されていません（意図的な制限）。
* 公開 API はアクセスパスワード、Host/Origin 検証を使用します。
